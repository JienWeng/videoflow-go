# UI and workflow audit — 27 September 2026

[Audit overview](2026-09-27-implementation.md) · [Handbook](../handbook/README.md)

## Is there too much or too little UI?

**Both, in different places.** Settings exposes many low-level choices before proving the basic route works. Create video has a suitably small form but lacks readiness, effective settings, truthful progress, and recovery information. The priority is to align controls with actual behavior and reveal advanced options when needed.

This is a **source-based workflow review**. Svelte check and build passed. Browser tooling returned “No browser is available”; layout, screenshots, keyboard interaction, contrast, touch targets, and actual narrow-screen behavior were not visually verified. Fixed-width concerns below are risks inferred from CSS, not claimed screenshot findings.

## What already helps

Create and Output are prominent navigation groups. Advanced contains the detailed workspace. Settings has functional tabs. Scenes includes stage filtering and recovery controls. Render errors include a friendly message and expandable detail. Projects exposes import/export, and the command palette is global. These are useful foundations to preserve while correcting behavior.

## Proposed beginner journey

1. Open an empty project and see “Configure AI”.
2. Choose one supported route, verify required models, and see what it can generate.
3. Describe one short video with style/format/language choices the route actually supports.
4. Review the request scope, then generate with persisted stage progress.
5. Preview/download the output, or resume the failed stage with existing artifacts intact.
6. Open Advanced only when editing characters, references, scenes, or shots is necessary.
