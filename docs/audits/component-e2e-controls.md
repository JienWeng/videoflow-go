# Observed E2E control inventory

Generated from the successful desktop/mobile mocked and real-router browser runs on 2026-11-11. These are visible DOM controls observed in tested fixture states, grouped by route and deduplicated by element kind/name. Shared navigation links are omitted. Names can change with project data. Empty labels identify controls needing title/label inspection; this lightweight DOM inventory is not a full accessible-name computation.

**Inventory does not mean interaction coverage.** Executed interactions are recorded in `component-e2e-coverage.md` and the JSON reports named there. Controls outside those explicit checks remain inventory-only, including most populated scene/asset editing, provider settings, canvas menus and destructive variants. Conditional controls that were not made reachable are absent.
