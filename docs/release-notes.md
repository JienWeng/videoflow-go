VideoFlow now routes AI generation through OpenRouter and includes a browser-based desktop download.

Download the ZIP for your operating system, extract the whole folder, then open **Start VideoFlow**. Enter your OpenRouter key in Settings. No Go or Node installation is needed. Projects remain in your user data folder when you update.

This is an unsigned preview. OpenRouter credits are required and generation is billable. FFmpeg is not bundled; install it for transcription, frame QA and caption burning. See **START HERE.txt** inside the download for details.

Automated provider/workflow tests and a live authentication/catalog check passed. Paid generation has not been verified end to end against the live account.
