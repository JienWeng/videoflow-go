# Unified workspace

Approved direction: the user accepted the interactive unified Studio proposal and stage-based disclosure on 2026-11-16 and requested implementation.

The main task is turning an idea into an approved story, references and video. Default to Studio's canvas; provide Story as another view of the project's actual scenes. Project summary stays accessible through a project menu. Keep settings and finished videos separate.

Combine characters/assets under Library tabs using the existing editors. Use one shared Create story dialog from Studio, Scenes and the command palette, reusing the existing guided creator including missing-character creation and reference review. Preserve /create, /characters, /assets and /scenes deep links. A single conversation selector retains native sessions and advanced management.

Scene tools disclose current/reached stages, fold earlier work and hide unrelated future sections until reached. Show all stages lets the user inspect every stage without executing anything. Earlier details and revision history remain reachable. Selection exposes a contextual action bar. Preserve all approval, ownership, charging and reconciliation gates; never imply unknown costs or authentication are verified. Keep drafts mounted across local view switches and guard actual navigation/overlay dismissal.

Approaches: flatten all editors into chat would conceal manual controls; cosmetic navigation changes alone would leave duplicate creation flows. Reuse existing editor components within a unified shell, retaining advanced routes as secondary destinations. This is the chosen direction from the proposal; docked rather than freely floating panels are the implementation choice for keyboard and responsive reliability.

No backend schema changes, new provider tools, paid calls, dependency additions or visual identity replacement. Mobile uses a single active pane. Verify empty/partial/completed projects, stage revisit without execution, dirty forms, dialog dismissal, deep links, selected item context, errors, keyboard access and mobile overflow.
